# Release v1.4.3 — Custom Bot Endpoint Audio Engine & Connection Testing

## New Features & Enhancements

- **Dedicated Bot Endpoint Audio Engine**:
  - Added a **Gunakan Bot Endpoint** toggle inside the Admin Song Manager for processing YouTube audio previews directly through your personal bot server.
  - Enables unlimited, on-demand audio trimming without relying on third-party cloud tier limits.

- **Real-Time Bot Connection Tester**:
  - Integrated a 1-click **Tes Ping** diagnostic tool that measures network latency and verifies bot server availability with clear status indicators (*Online*, *Offline*, and response times).

- **Flexible Endpoint Presets & Auto-Sync**:
  - Built-in host presets for instant 1-click configuration between production server hosts and local development setups.
  - Automatically remembers and restores your configured bot endpoint across browser sessions without needing manual re-entry.

- **Adaptive Trimmer Actions**:
  - The song trimmer button automatically adapts its processing mode, visual styling, and status feedback dynamically based on whether cloud or your custom bot endpoint is selected.
