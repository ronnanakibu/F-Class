# Release v1.3.0 — The Frequency (Class Mixtape & Interactive Audio Player)

## Features & Highlights

- **Replaced "The Atmosphere" with "The Frequency"**:
  - Transformed the static chaos section into an interactive cybernetic music deck celebrating the authentic soundtrack of Class F.
  - Features spinning vinyl disc animation, dynamic sound wave frequency visualizer, and authentic 30-second audio stream previews.
- **Interactive Audio Controls & Queue**:
  - Full playback controls: Play, Pause, Next Track, Previous Track, Seek Timeline bar, Volume control, Mute toggle, and Single-Track Repeat.
  - **Class Playlist Queue**: Browse the curated queue of tracks with album thumbnails, contributor badges, and instant one-click track switching.
  - Direct streaming shortcuts to listen to full songs on Spotify.
- **Student Song Attribution & Memory Notes**:
  - Each song highlights the student who recommended it (or marks it as a Class Anthem) with initial avatars and custom memory quotes detailing why the song is special to the class.
- **Automated Music Search & Metadata Ingestion in Admin Console (`/admin`)**:
  - Added a dedicated **"Playlist Lagu"** tab in the admin panel to view, test-listen, and curate class songs.
  - **Auto-Fetch Music Search**: Simply type a song title, artist, or paste a Spotify link — the engine automatically fetches:
    - Official Song Title & Artist Name
    - Album Name
    - High-Resolution (HD 600x600) Cover Artwork
    - Official 30-second playable audio stream preview
    - Streaming links
  - Easy attribution dropdown listing all 31 classmates, class anthems, or custom names.
  - One-click "Gunakan Lagu Ini" button to instantly populate form fields without manual typing.
