# Release v1.3.2 — Unified Admin Portal, Milestone Showcase Manager & God Mode

## New Features & Enhancements

- **Unified Student Management Hub**:
  - Consolidated student profile pictures, cropping studio, identity editor, and raw database editor into a single unified management section in the Admin Console.
  - Introduced responsive sub-tab switching between *Form & Identitas*, *Foto Profil & Crop*, and *Raw Code JSON* for a clean, distraction-free workflow.
  - Added 1-click *Unduh JSON* and *Salin Kode* actions for instant data backups and manual syncing.

- **The Journey Milestone Showcase Manager**:
  - Built full administrative control for the class timeline and milestone slideshow (*The Journey of CE F*).
  - Users can now add new milestones, modify existing stories, customize accent colors, select semesters, and adjust display ordering with interactive up/down reordering.
  - Supports both high-resolution photography and video media links.

- **God Mode — Comprehensive Website Content Control**:
  - Added a dedicated *God Mode* dashboard enabling real-time customization of public website copy and media without code changes.
  - Customize the Hero section headlines, badge tags, and mockup hardware artwork.
  - Edit the Manifesto philosophy tagline, mission narrative, and highlight statistics (active projects, practicum hours).
  - Configure footer copyright attribution and official class social media links dynamically.

- **Resilient Multi-Tier Cloud & Serverless Storage**:
  - Overcame serverless read-only deployment filesystem constraints with an intelligent tiered storage engine (in-memory caching, serverless temporary storage, and optional cloud storage synchronization).
  - Profile picture uploads seamlessly fallback to embedded high-resolution data packages when physical storage is restricted, guaranteeing 100% upload success across all deployment environments.
