# Release v1.2.0 — Custom Project Showcase & Interactive Admin Suite

## Features & Highlights

- **Clean Showcase (What We Build)**: Removed all placeholder and demo projects. The portfolio now features exclusively the class developer's authentic flagship projects:
  - **EnglishQuest**: An interactive English learning platform with game-based exercises, real-time feedback, and dynamic progress tracking.
  - **WhatsApp Bots (WABOT2.0)**: Multi-device automation engine serving as a class assistant, Instagram story scraper & web synchronizer, and campus smart utility.
- **Dedicated Project Banners & Asset Organization**:
  - Prepared the `public/projects/` directory for high-resolution project banners and screenshots.
  - Built-in cybernetic visual fallback for projects without custom images, ensuring seamless aesthetics.
- **WhatsApp vs Web Smart Action CTAs**:
  - Automatically detects WhatsApp links (`wa.me` or `whatsapp.com`) and displays a dedicated emerald green **"Coba Bot WA"** button with a chat icon.
  - Regular links seamlessly render a cyan **"Live Web"** button with an external globe icon.
- **Full Project Management in Admin Console (`/admin`)**:
  - Added a dedicated **"Proyek Kelas"** tab in the admin panel to view, search, and manage all class projects.
  - **Tambah Proyek Baru Modal**: Easily publish new projects built by yourself or classmates with comprehensive metadata:
    - Project Title & Category dropdown
    - Detailed Project Description & Feature highlights
    - Tech Stack tags (e.g. Next.js, Python, Arduino)
    - Team & Creator contributors list
    - GitHub Repository URL
    - Live Web Demo or WhatsApp Bot link
    - Custom Banner Image path with helper guide
    - One-click **DEV'S PICK ⭐** highlight toggle with golden glowing badge.
  - **In-Place Editing & Deletion**: Update project information on the fly or remove projects with confirmation safeguards.
