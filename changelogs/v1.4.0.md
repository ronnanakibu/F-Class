# Release v1.4.0 — Integrated Class Attendance Portal & Administrative Management Hub

## New Features & Enhancements

- **Student Attendance Portal (`/absensi`)**:
  - Launched a dedicated, mobile-friendly digital attendance portal for all 20 class members.
  - Secure authentication using NIM and personal password credentials (with initial default set to the last 4 digits of each student's NIM).
  - Real-time meeting check-in supporting *Hadir*, *Sakit* (with medical explanation / note), and *Izin*.
  - Personalized attendance statistics dashboard displaying attendance rate percentage, total meetings, and attendance counters with colored progress indicators.
  - Interactive attendance history log tracking all past course meetings, statuses, and timestamps.
  - Built-in personal password management modal allowing students to update their credentials anytime.

- **Class Member Interactive Prompt Banner**:
  - Added a modern glassmorphic invitation card on the main website below the Students gallery (*"Apakah kamu salah satu dari mereka?"*).
  - Provides instant 1-click redirection directly to the `/absensi` portal with clear login instructions.

- **Administrative Class Attendance Hub (`/admin`)**:
  - Integrated a dedicated **📋 Absensi Kelas** console tab for class leaders and secretaries.
  - **Quick Meeting Creator**: Fast session initialization with autofill from the weekly 29-slot course schedule (Senin s/d Jumat), auto-populating course title, lecturer name, and class hours.
  - **Live Attendance Grid**: Real-time status cards for all 20 students with 1-click status switching (**H**adir, **S**akit, **I**zin, **A**lpa) and instant counter summaries.
  - **1-Click "Tandai Semua Hadir"**: Accelerated attendance recording allowing the entire class to be marked present in a single tap.
  - **Meeting Session Controls**: Full control to open, lock/finalize, and reopen attendance sessions.
  - **Full Semester Matrix & CSV Export**: Complete attendance recap matrix across all meetings with automatic calculation of attendance rates and warning alerts for students below 75%, exportable directly to CSV/Excel for academic reporting.

- **Persistent Cloud Database Infrastructure**:
  - All class schedules, meetings, attendance logs, and student credential profiles are stored and automatically synchronized with persistent cloud database storage under a dedicated secure database repository.
