# Gallery Media Folder (`public/gallery/`)

Folder ini dikhususkan untuk menyimpan foto dan video milestone/momen kelas untuk **Apple-Style Slideshow Showcase** dan **Gallery**.

### Format yang Didukung:
- **Foto:** `.jpg`, `.jpeg`, `.png`, `.webp` (Rekomendasi rasio: 16:9 atau 21:9, minimal lebar 1920px untuk tampilan jernih).
- **Video:** `.mp4`, `.webm` (Rekomendasi H.264 / AAC, loop ambient 1080p).

### File Bawaan (Default):
- `slide-orientation.jpg`
- `slide-digital-logic.jpg`
- `slide-programming.jpg`
- `slide-uas.jpg`
- `slide-esp32.jpg`
- `slide-iot.jpg`
- `slide-future.jpg`

*Catatan: Jika file belum dimasukkan, Apple Slideshow akan otomatis menampilkan visual futuristik ambient glow.*
