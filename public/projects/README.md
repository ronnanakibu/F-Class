# Projects Media Folder (`public/projects/`)

Folder ini dikhususkan untuk menyimpan gambar mockup / banner showcase proyek di section **What We Build** (`Projects.tsx`).

### File Rekomendasi:
1. `englishquest.jpg` / `englishquest.png`
   - Banner untuk proyek **EnglishQuest** (`https://englishquest-web.vercel.app/`).
2. `whatsapp-bot.jpg` / `whatsapp-bot.png`
   - Banner untuk proyek **WhatsApp Bots (WABOT)** (`https://wa.me/+6285188742549`).

### Panduan Gambar:
- **Rasio Aspek:** 16:9 atau 16:10 (misalnya `1200 x 675` px atau `800 x 450` px).
- **Format yang didukung:** `.jpg`, `.jpeg`, `.png`, `.webp`.

*Catatan: Jika file gambar belum dimasukkan, kartu proyek otomatis menampilkan visual cybernetic placeholder beraksen neon yang estetik.*
